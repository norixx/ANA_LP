セール運賃に関するご注意

  • 2026年5月19日以降搭乗分の国内線は、複数名でのANA SKY コインご利用に一部制限が発生しております。詳細は(国内線・国際線) ANA SKYコインのご利用についてをご覧ください。ご迷惑をおかけすることをお詫び申し上げます。
  • お客様のご旅程により、コンビニ支払いをご利用いただけない場合があります。詳細はコンビニエンスストアでのお支払いからご確認ください。
  • 運賃額は予告なしに変更になる場合があります。
  • 運賃額は、ご購入手続き時点で有効な金額が適用されます。航空券ご購入後にご利用便の運賃額に変更があった場合、差額の収受または払い戻しは行いません。詳しくは「運賃計算ルールについて」をご覧ください。
  • 運賃適用基準日は2026年1月14日（水）です。購入日によっては、運賃額の記載例と異なる場合があります。
  • 往復運賃は原則、往路・復路を同時に購入いただく時に適用されます。
  • 満2歳以上12歳未満のお子様がご購入する場合、「小児割引」を適用します。
  • 以下の手帳をお持ちのお客様は「障がい者割引」を適用します。 身体障害者手帳、戦傷病者手帳、療育手帳、精神障害者保健福祉手帳
  • セール運賃は購入後の変更はできません。搭乗当日、出発空港においてご予約便より前の便に空席があった場合でも変更は承れません。
  • 払い戻し時に適用される「取消手数料」は航空券の使用状態によって異なります。詳しくは「国内線の変更払い戻しのルール」をご確認ください。
  • すでに別の運賃で航空券を購入済みの場合は、所定の手数料を頂戴し払い戻しのうえ、あらためて予約、購入いただく必要があります。払い戻し額とセール運賃額との差額をご確認のうえご検討ください。
  • 運賃の他に対象空港発着便利用時のみ「旅客施設使用料」を申し受けます。

この環境で実現できること

クライアントサイド（ブラウザ）でAPIからデータを取得し、動的カードをロードする処理をスマートに表現します。

ビルドプロセスの最適化

⚡ JS / CSS のミニファイ

Vite内蔵の esbuild が不要なスペースや改行を全て削除し、劇的にサイズを縮小します。

🖼️ 画像自動最適化 (Sharp)

`src/images/` に配置された画像は、ビルド時に自動でロスレス/不可逆圧縮され、ファイルサイズを削減します。

🚀 Alpine.js の動的出力
