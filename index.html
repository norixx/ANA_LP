Next-Gen LP Starter

Vite + EJS + Tailwind + Alpine

1枚物のランディングページ（LP）用のモダンテンプレート。EJSのパーツ管理と、Alpine.jsによるブラウザ上での超軽量・動的カード生成（API連携対応）を両立。

詳細を見る 技術構成を見る

この環境で実現できること

クライアントサイド（ブラウザ）でAPIからデータを取得し、動的カードをロードする処理をスマートに表現します。

ビルドプロセスの最適化

⚡ JS / CSS のミニファイ

Vite内蔵の esbuild が不要なスペースや改行を全て削除し、劇的にサイズを縮小します。

🖼️ 画像自動最適化 (Sharp)

`src/images/` に配置された画像は、ビルド時に自動でロスレス/不可逆圧縮され、ファイルサイズを削減します。

🚀 Alpine.js の動的出力

APIデータを非同期で取得し、カードを瞬時に生成。ページの初期表示速度を落としません。
